# Python Crash Course

## Core python Concepts

### The print function

- We first start by learning the `print()` command.
- It outputs whatever it is inside the brackets.
- When you want to print anything just type it inside the brackets

### Escape sequences

- Escape sequences are used to jump into other lines. It is a combination of two or more characters.
- `\n` This creates a new line. It always starts with a backslash `\`
- `\t` This creates a tab.

### Data types

1. strings
    - This are characters
    - Strings are surrounded by `""`
    - Example of a string `"12+8`, `"Hello World"`,`'Welcome to Derry'`
    - In Python you can use either `""` or `''` quotation marks for a string.
    - You can write multiple line strings using three quotes`(""" """)`

### Variables

- This is a container that stores data.
- It can be anything such as a number, text, decimal, filename etc.
- It can be accessed anywhere on the program and as many times as needed by simply writing its name.
- We write a variable by writing is name, using the assignment operator `=` and the value of the variable, it can be text, numbers etc.
- Example of a variable is `acc = 89765434567810`
- When accessing varibales don't add quotation marks around the variable name.
- When creating variables:
    1. A variable name can't start with a number. You can include numbers but not at the beginning of the name.
    2. A variable name can only have `_` as the only special character, you can't use other special characters.
    3. Python is a case sensitive language. Be keen with the naming of your variables.
